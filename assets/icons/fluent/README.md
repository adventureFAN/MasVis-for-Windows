# Microsoft Fluent UI System Icons used by MasVis for Windows

Source project: Microsoft Fluent UI System Icons  
License: MIT

MasVis for Windows bundles selected official Fluent UI System Icons as SVG
assets for application actions and controls. The artwork is recolored in memory
for the current Light/Dark theme where appropriate; the bundled source SVGs are
kept as project assets.

The corresponding MIT license text is stored in
`LICENSE-Microsoft-Fluent-UI-System-Icons.txt` in this directory.

The Play toolbar action uses Microsoft's official
`ic_fluent_play_24_regular.svg`, stored locally as `play.svg` to match the
project's short asset naming convention.
