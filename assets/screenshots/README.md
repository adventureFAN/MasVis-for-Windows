# README screenshots

These screenshots are intended for the public GitHub README.

- `main-window.png` — MasVis for Windows detailed-report UI.
- `dynamics-assessment.png` — Dynamics Assessment on the deliberately louder `Eternal Desert LOUD` test version.
- `dynamics-comparison.png` — Dynamics Comparison between the `Eternal Desert` Loudness War master and the controlled vinyl-like transfer simulation made from that same already-compressed source.

The comparison screenshot is a controlled practical/stress-test example. The vinyl-like file is **not an actual vinyl master, pressing or needledrop** and is not a complete physical model of vinyl cutting/playback. It deliberately changes peak/crest structure without dynamic expansion, demonstrating how measured DR can rise substantially while aligned Short-Term loudness dynamics remain essentially unchanged.

The screenshot is used to demonstrate expected behavior, not as proof that the application can infer mastering history or that a particular real-world vinyl release used the same master as another format.
