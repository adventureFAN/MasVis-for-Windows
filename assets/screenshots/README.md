# README screenshots

These screenshots are intended for the public GitHub README.

- `main-window.png` — MasVis for Windows detailed-report UI.
- `dynamics-assessment.png` — Dynamics Assessment on the deliberately louder `Eternal Desert LOUD` test version.
- `dynamics-comparison.png` — Dynamics Comparison between the `Eternal Desert` Loudness War master and the controlled vinyl-like transfer simulation made from that same already-compressed source. Measured DR rises from 6.5 to 10.4 while aligned loudness dynamics remain essentially unchanged.
- `dynamics-comparison-equal-dr.png` — Dynamics Comparison between the original `Eternal Desert` Reference and the same vinyl-like transfer simulation. Both measure DR 10.4, while aligned loudness dynamics differ substantially.

The comparison screenshots are controlled practical/stress-test examples. The
vinyl-like file is **not an actual vinyl master, pressing or needledrop** and is
not a complete physical model of vinyl cutting/playback. It deliberately changes
peak/crest structure without dynamic expansion.

Together, the screenshots demonstrate two complementary points: measured DR can
change substantially while aligned Short-Term loudness dynamics remain
essentially unchanged, and essentially equal DR values can coexist with clearly
different aligned loudness dynamics.

They are used to demonstrate expected behavior, not as proof that the
application can infer mastering history or that a particular real-world vinyl
release used the same master as another format.
