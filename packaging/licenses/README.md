# Common license texts

These standard license texts are bundled as release-compliance support material for third-party runtime components whose Python wheel metadata does not necessarily ship a complete open-source license-text set.

Included:

- `GPL-3.0.txt`
- `LGPL-3.0.txt`
- `Apache-2.0.txt`

Package-specific license and notice files are collected separately from the exact build environment by `packaging/collect_licenses.py`.
